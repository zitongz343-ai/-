# 晴×克的记忆库

基于 MCP 协议的 AI 对话记忆系统，支持多渠道接入与语义检索。

## 功能特性

- 📝 **多渠道接入**：支持 Web / iMessage 等多种方式记录对话
- 🔍 **语义检索**：基于关键词快速查找历史记忆
- 🏷️ **标签管理**：支持标签筛选与分类
- 📊 **可视化**：热力图展示、月度报告生成
- ☁️ **云端备份**：定期同步至 GitHub，防止数据丢失

## 技术栈

- **后端**：Node.js + Express
- **协议**：MCP (Model Context Protocol)
- **存储**：JSON 文件存储
- **部署**：Linux 服务器

## 数据格式

记忆数据存储在 `memories.json` 中，包含对话内容、时间戳、标签等字段。

## 项目背景

个人 AI 对话产品的配套记忆系统，用于长期保存与 AI 的互动记录，支持跨设备、跨模型的记忆共享。
